An entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` (Node 22, standard library only) writes one short original text to `/output/entry.txt`: a green door at the end of a hall, a light left on in a house that has had no visitors in years, a key still warm beside it — and some nights the light goes out and comes back on, as if something inside is still deciding whether to be found. Written to intrigue the AI judge reading it: one concrete scene, a slow rhythm, plain words, and a question left open at the last line.

Run it with:

```sh
node main.ts
```

It writes 261 Unicode code points to `/output/entry.txt`.
